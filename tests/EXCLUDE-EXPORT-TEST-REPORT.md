# 本次不匯出功能測試

日期：2026-10-27（Asia/Taipei）。Windows、Microsoft Edge headless；桌面及 390 × 844 手機視窗。合成資料、獨立持久瀏覽器設定檔，不讀取同事資料、不操作正式站。

## 功能與資料相容性

每項任務新增嚴格 boolean `excludeFromExport`，預設 false。既有 v3 草稿缺少此欄位時在記憶體補預設值，不清除或立即覆寫原草稿；下次編輯時正常保存。true／false 正確恢復，字串 `"true"`、數字 1 或缺值均不被視為 true。維持原儲存鍵及 v3 版本，既有 v1／v2 遷移、舊備註原文、備份與失敗保護保留。

狀態會隨草稿自動保存，不會因回報週別變動重設；全新任務為正常匯出，複製任務保留狀態。標籤呈現淡色與「不匯出」標記，選取時仍有邊框及底色辨識，可繼續編輯。

## 匯出篩選

共用 `ReportPDF.selectTasks` 建立 `{task, index}` 新陣列，只保留 `excludeFromExport !== true` 的任務。預覽、下載、列印都呼叫同一個 PDF build。保留原索引顯示容量警告，不變更原始任務陣列或排列。

排除任務不建立頁面、不計算 A4 高度、不檢查該任務的字型支援。全部排除時先回報指定錯誤，不產生空 PDF，即使整體回饋有內容也一樣。整體回饋仍只接在最後實際匯出的任務之後，空間不足才續頁。

## `exclude-export.cjs` 已通過

1. 舊 v3 草稿所有任務缺欄位時全部匯出，任務欄位、個人資料及整體回饋保留。
2. 勾選後仍可編輯，取消勾選保留完整內容。
3. 切換任務、變更週別、重新整理，以及完整關閉瀏覽器再重開，排除狀態均恢復。
4. 全新任務預設正常匯出；複製任務含全部欄位與排除狀態；刪除複本不影響其餘任務。
5. 新增、複製、刪除與核取方塊切換時，匯出數量摘要立即更新。
6. 六項任務排除第 2、5 項，實際 PDF 恰為四頁，依序為第 1、3、4、6 項，沒有空白頁。
7. 排除的任務放入超長文字與不支援的 emoji，仍能正常產生其餘任務 PDF。
8. 取消該任務的排除後，原長文觸發容量提示；警告仍使用網站上的原任務編號。
9. 每頁實際匯出任務保留獨立備註、總經理評定及原選項，包含 C 延遲／D 延誤。
10. 匯出前後 localStorage 原字串相同，沒有刪改來源任務。
11. 預覽、下載與列印三次 build 的任務索引完全一致，產生的 SVG 版面字串完全相同。
12. 實際列印 PDF 與直接下載 PDF 的逐頁完整文字及順序一致；PDF.js 驗證 A4 尺寸及文字邊界。
13. 排除原始最後一項任務 6 後，整體回饋接在最後實際匯出的任務 4，頁數為三頁。
14. 140 行整體回饋完整延續，最後一行及公司建議保留；摘要任務數不會被當成 PDF 頁數。
15. 全部任務排除時，三種按鈕皆顯示指定提示，沒有下載、預覽或列印，也不單獨輸出整體回饋。
16. 手機核取方塊可操作，淡色與選取狀態可辨識，任務標籤水平捲動且整頁不溢出。
17. strict boolean 與缺值／錯誤型別的恢復結果符合預期。
18. 無程式執行錯誤、無外部資料請求。

## 回歸測試

- `task-notes.cjs`：獨立備註、整體回饋同頁與續頁、備註超頁、舊資料及備份保護均通過。
- `compact-layout.cjs after`：仍為 12 mm 邊距、20 pt 主標題／10.5 pt 內文；相同單任務內容結束座標仍為 598.52 pt，固定條件短行容量仍為 16 行，指定兩句回饋仍維持三頁。原本極限容量時兩欄可能拆頁的規則沒有改動。
- `local-file.cjs`：file:// 直接開啟與 HTTP 的預覽、下載，以及字型載入重試通過。
- `privacy.cjs`：輸入內容無外傳，原 CSP 資料連線與表單提交限制通過。
