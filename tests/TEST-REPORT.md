## 發布前隱私檢查

`privacy.cjs` 將合成資料填入各文字欄位，實際預覽及下載 PDF，驗證無 POST、URL 或請求本文無填寫值、請求限本站靜態資源。另刻意測試 fetch 對外及同站資料連線、HTML 表單提交，均由新增 CSP 阻擋。報告及測試產物、瀏覽器設定檔、套件和機密檔名的忽略規則已以 Git check-ignore 驗證；只在被排除的測試產物目錄建立暫存 Git 儲存庫，真正專案未初始化或推送。

## 補充說明同頁更新

依最新需求，共用補充說明接在最後一項任務的總經理評定之後；空間足夠不新增頁面，空間不足才延續，沒有填寫的欄位省略。`supplement.cjs` 驗證一項任務加三個短補充欄位仍為一頁、任務已接近頁底時補充才換頁，以及長補充先利用當頁空間並完整延續至最後一行。更新既有 PDF 下載、列印與文字擷取測試的頁數及同頁出現規則。

## 本機 PDF 讀取修正

原 PDF 字型使用 fetch，直接雙擊 HTML 的 file:// 模式會遭瀏覽器阻擋。改為按需載入本站的字型資料腳本，避免依賴本機 fetch。`local-file.cjs` 已實測 file:// 及 HTTP 兩種模式：實際開啟 PDF 預覽、下載並解析一頁 PDF，沒有程式錯誤。模擬字型資料檔載入失敗時有具體提示；恢復檔案後在同頁重試可成功。更新後重跑既有瀏覽器及 PDF 解析測試。

## 回報週別更新驗證

已將回報日期改為共用回報週別，預設當週，網站及每張任務 PDF 均顯示週一至週日範圍。`report-week.cjs` 實測當週換算、跨年、閏年、無效第 53 週、重新整理恢復、v1 舊日期草稿轉成 v2 週別且保留原任務與補充內容，以及未選週別阻止輸出。手機寬度未溢出。更新後重新執行 `browser.cjs` 與 `verify-pdf.cjs`，包含每張任務頁的完整週別範圍文字與頁面邊界檢查。

測試日期：2026-10-22（Asia/Taipei）。環境：Windows、Microsoft Edge（Playwright headless），桌面 1440 × 1000、手機視窗 390 × 844。所有資料均為合成測試文字，使用隔離瀏覽器，不寫入網站初始資料。

PDF 視覺檢查：以 Poppler 將實際生成的 PDF 轉成圖片，檢查文字顯示、表格、勾選方框、留白與補充分頁。字型測試曾發現可變字型與子集化造成缺字，最終採用固定 Regular 400 的標準 TrueType、完整內嵌並關閉非必要字形替換；最終 PDF 已重新解析與檢視。單份 PDF 的固定字型負擔約 4.4 MB，多項任務共用同一份字型。

`verify_pdf.py` 另提供 pypdf 的驗證方式；完整內嵌中文字型使其解析明顯較慢。主要完成驗證以 PDF.js 結果為準。
