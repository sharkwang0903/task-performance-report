## 既有功能回歸

更新舊測試的欄位與版本預期後，重新執行：

- `browser.cjs`：任務操作、至少十項任務、儲存、清除、三頁 PDF、整體回饋同頁、超頁、預覽及列印。
- `verify-pdf.cjs`：下載與列印版 PDF 頁數、中文字擷取、備註區與評定選項、頁面邊界。
- `report-week.cjs`：一般、跨年、閏年、無效週別與 v1 相容。
- `edge-cases.cjs`：瀏覽器重啟、長回饋、缺字警示、未知版本與損毀資料保護、儲存失敗。
- `local-file.cjs`：直接開啟 HTML 與 HTTP 兩種模式的預覽及下載，字型載入失敗與重試。
- `privacy.cjs`：無輸入資料外傳、CSP 阻擋資料連線與表單提交。

## 視覺檢查與產物

Poppler 將實際輸出的 PDF 轉成 PNG，檢查個別備註、總經理評定、最後頁同頁整體回饋、獨立回饋頁、長文續頁及列印版；沒有觀察到缺字、重疊或裁切。手機及桌面表單另存截圖檢查。

主要測試產物（皆在已忽略的 `tests/output/`）：

- `notes-three.pdf`：三項任務與獨立備註。
- `notes-feedback-same.pdf`：三項任務加最後頁整體回饋。
- `notes-feedback-next.pdf`：空間不足才換頁。
- `notes-feedback-long.pdf`：整體回饋長文延續。
- `notes-print.pdf`：列印備用輸出。
- `notes-migrated.pdf`：舊備註完成分配後輸出。
- `task-notes-results.json`：自動化結果。
